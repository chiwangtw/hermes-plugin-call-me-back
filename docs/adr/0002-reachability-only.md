# 0002 只提供可達性，用法交給調度者或其他 skill

**Status**：accepted（2026-09-25）

派工之後怎麼驗收、回報要寫什麼、Task 裡放什麼、什麼時候派、要不要排隊，每個人的做法不同，也會隨經驗改變。

做法：call-me-back 只提供「做得到什麼、怎麼接上」：列出與讀取 Session、送字與中斷、派工、列出與關閉 Task、通知、叫醒。用法交給調度者當下判斷，或交給任務管理類 skill、範例（recipe）。叫醒訊息只帶事實（哪個 Task、停下原因、執行者的最後回覆）與可用的 tool，不帶「接下來該怎麼做」的指示。

為什麼：

- 可達性相對穩定，用法常變。兩者拆開，改用法不必動 plugin，升級 plugin 也不會打亂既有的流程。
- 執行者本身讀得到專案與人自己的規範，不必由這裡再加一層限制。

代價：沒有規定的回報格式。調度者要自己從最後回覆和畫面判斷 Session 的狀態；想要固定流程的人，要另外寫 skill 或在派工的 prompt 裡講清楚。
