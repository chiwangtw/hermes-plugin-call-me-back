# 0008 派工後檢查啟動畫面，並自動登記未知的目錄

**Status**：accepted（2026-09-25）

執行者第一次在某個目錄啟動時，可能先問「是否信任這個資料夾」；Codex 在新加的 hook 生效前會要求「Hooks need review」。這些畫面出現在第一個回合之前，任何 hook 都還沒觸發：不會有停下事件，人收不到通知，調度者也不會被叫醒，只會以為它還在跑。另外，Orca 只在它認得的目錄開終端，派到一個沒登記過的目錄會直接失敗。

做法：

- 派工後等幾秒（`startup_check_seconds`，預設 8，設 0 關閉）讀一次畫面。認出啟動提問（資料夾信任、hook 審查、「Press enter to continue」等）時，派工結果標記 `waiting_for_human` 並附上畫面，由調度者用 `call_me_back_send` 回答，或轉問人。
- Orca 回「找不到這個目錄」（`selector_not_found`）時，先執行 `orca repo add --path <目錄>` 登記，再重試一次。

為什麼：卡在啟動畫面沒有任何訊號，只有看畫面才知道。在派工的那一輪就把畫面交回調度者，比等一個永遠不會來的叫醒好。

代價：

- 派工 tool 會多等幾秒才回。
- 啟動提問用文字比對認出來；執行者改了提示文字就要跟著更新。
- 只檢查一次，之後才出現的提問抓不到。
- 自動登記會在人的 Orca 裡多出一個 repo。
